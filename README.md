# ⚖️ Calculadora de IMC e Cadastro de Usuário em Java


Um sistema simples em console desenvolvido em Java que interage com o usuário para coletar dados cadastrais (como Nome, CPF, Idade, Peso, Altura e Estado Civil) e realiza o cálculo automático do **Índice de Massa Corporal (IMC)**.

## 🚀 Funcionalidades

* **Interação Dinâmica:** Coleta de dados em tempo real utilizando a classe `Scanner`.
* **Armazenamento Adequado:** Uso correto dos tipos de dados do Java (como `String` para CPF por conta da formatação e zeros à esquerda).
* **Cálculo de IMC:** Processamento matemático utilizando tipos de ponto flutuante (`double` e `float`) para maior precisão.
* **Exibição Formatada:** Resumo completo e organizado dos dados inseridos ao final da execução.
